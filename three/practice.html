6.4 实战：3D 柱状图数据可视化 ​

前面三页备齐了全部零件：场景相机渲染器、几何体材质灯光、动画循环与拾取。本页把它们总成一个完整作品——3 个城市 × 12 个月的 3D 柱状图，36 根柱体带入场生长动画、悬停高亮与数值面板、阻尼运镜。这也是把 ECharts 快速上手里的 2D 柱状图与 Canvas 实战的手写图表思想搬进三维的一次落地。

概念解析 ​

从 2D 柱状图到 3D ​

2D 柱状图的映射是"类目 → x 坐标、数值 → 柱高"；3D 多出一个维度，正好容纳第二个类目轴：月份铺 x、城市铺 z、数值依然是高度。2D 里靠手写换算或 ECharts 引擎完成的"数据到像素"映射，在 3D 里变成"数据到世界坐标"的映射，思路完全同构——先归一化，再乘视觉尺度。多出来的成本是视角：2D 图表俯视即全部，3D 图表必须允许用户旋转缩放才能看全被遮挡的柱体，这就是 OrbitControls 的席位。

数据到视觉通道的映射 ​

本例的映射规则只有三条：月份（12 个类目）→ 地面 x 网格位置，城市（3 个类目）→ 地面 z 网格位置，数值（0~100）→ 柱高与颜色。柱高用 0.4 + v * 3.2 把归一化值 v 放大到视觉尺度，并保留 0.4 的下限让最小值也可见；颜色用 HSL 插值，色相从 0.66（蓝）渐变到 0（红），蓝低红高是图表的习惯约定，比写死一组色板更能适应数据范围变化。

典型应用场景 ​

  • 多维报表的立体呈现：两个类目轴 + 一个数值轴是 3D 柱状图的甜区；
  • 大屏与展厅：生长动画加缓慢自转，观赏性强于平面图表；
  • 需要强调体量感的对比：高度加颜色的双通道编码，差异一眼可辨。

反过来要清醒：精确的数值阅读仍是 2D 图表的主场，3D 存在透视遮挡与读数误差。3D 图表是"展示与探索"的增强，不是"精确报表"的替代——选型边界在对比分析模块还会展开。

核心 API 与原理 ​

场景搭建清单 ​

按 6.1~6.3 的套路列清单，逐条落实即可：透视相机取高位斜视机位（fov 45，一次看全 12×3 柱阵）；环境光 0.6 加平行光 2.5，不求阴影只求层次；GridHelper 当地面"坐标纸"，尺寸按数据网格范围取，别让柱子悬在网格外；可选 scene.fog 让远处柱体轻微淡出、增强纵深，雾色必须与背景色一致才自然；OrbitControls 开阻尼，target 对准柱阵中心偏上。

柱体实现与关键坑：geometry.translate(0, 0.5, 0) ​

36 根柱体用普通 Mesh 循环创建即可，共享同一份 BoxGeometry、各自一份材质（颜色不同且要单独高亮）。这里埋着全页最重要的一个坑：

js
const geo = new THREE.BoxGeometry(0.6, 1, 0.6)
geo.translate(0, 0.5, 0) // 把几何体原点从中心移到底面中心
// 之后 mesh.scale.y = h 才会"从地面向上生长"

BoxGeometry 的原点默认在几何中心，缩放以原点为锚：不 translate 的话，scale.y = 0.3 会让柱体向上下两端同时缩短，下半截直接陷进地面以下，生长动画也会变成"从中间向两端伸"。把几何体顶点整体上移半个高度后，原点落在底面中心，缩放就只剩"从地面拔高"一种语义。这个技巧对所有"以底为锚"的缩放都适用。另外柱体数量级上到数千根时，优化方向是 InstancedMesh——一次 draw call 画全部实例，代价是单柱定制（如 hover 变色）要改用 instanceColor，此处 36 根完全用不上。

HSL 颜色映射 ​

js
const v = value / 100 // 归一化
const color = new THREE.Color().setHSL(0.66 * (1 - v), 0.75, 0.5)
// v = 0 → 色相 0.66（蓝）；v = 1 → 色相 0（红）

HSL 的色相环上做线性插值，比在 RGB 通道上插值得到的渐变更均匀、更符合直觉，这是数据可视化的惯用手法（ECharts 的 visualMap 渐变同理）。饱和度与亮度固定，只让色相承载数值信息，避免多个通道一起变造成的阅读混乱。

hover 数值：为什么用 DOM 面板而不是 3D 文字 ​

悬停柱体时在画布下方的 DOM 面板显示"城市 · 月份 · 数值"。刻意不在 3D 场景里放文字，原因很实际：Three.js 没有内置文本元素，3D 文字要么用 Troika/SpriteText 之类的库把文字栅格化成纹理贴到平面上，要么自己画 CanvasTexture——字号、DPR 清晰度、永远面向相机的广告牌逻辑、遮挡关系，每一样都要额外处理，复杂度与"显示三个字段"的收益完全不成正比。DOM 面板由浏览器排版引擎负责，清晰、可选中、改样式零成本；3D 拾取结果同步到 HTML 只需在 hover 目标变化时更新一次响应式状态。这是"3D 场景 + DOM 信息层"混合架构的典型取舍，前页的信息条同理。

入场生长动画 ​

每根柱的 scale.y 从 0.001 缓动到目标高度，逐柱错开 30ms，delta time 驱动：

js
const t = (animTime - k * STAGGER) / DURATION // 第 k 根的局部进度
const p = t < 0 ? 0 : t > 1 ? 1 : t           // 夹取到 0~1
bar.scale.y = Math.max(0.001, bar.userData.fullH * easeOutCubic(p))

两个细节：初始值取 0.001 而不是 0——缩放为 0 的几何体会退化成平面，射线拾取不到，动画起点 hover 会失灵；动画播完总时长后就停手，不再每帧写 scale，帧循环只留 controls.update 与拾取，避免无意义的属性写入。重播只需把 animTime 归零。

完整代码示例 ​

将指针移到柱体上查看数值

左键旋转 / 滚轮缩放 / 右键平移；悬停柱体查看城市、月份与数值，颜色越红数值越高。

试试：入场时 36 根柱体按错峰节奏从地面生长出来（可点"重播生长动画"再看一遍）；按住左键绕柱阵旋转，从低角度观察高柱对矮柱的遮挡；把指针移到柱体上，柱体提亮且底部面板同步显示"城市 · 月份 · 数值"，颜色越红数值越高。

核心代码与组件逻辑一致，可直接复制复用：

vue
// 文件: docs/.vitepress/components/three/ThreeBarChart.vue
<template>
  <div class="demo-card">
    <div ref="stageRef" class="stage3d"></div>
    <div class="control-row">
      <p class="info-bar" v-text="infoText"></p>
      <button class="ctrl-btn" @click="replay">重播生长动画</button>
      <p class="tip">左键旋转 / 滚轮缩放 / 右键平移；悬停柱体查看城市、月份与数值，颜色越红数值越高。</p>
    </div>
  </div>
</template>
<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue'
const stageRef = ref(null)
const DEFAULT_TIP = '将指针移到柱体上查看数值'
const infoText = ref(DEFAULT_TIP)
const CITIES = ['北京', '上海', '深圳']
const MONTHS = ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月']
// 内置示例数据：3 城市 × 12 月，数值 0~100
const DATA = [
  [62, 58, 70, 75, 82, 88, 95, 91, 84, 78, 69, 65],
  [55, 60, 66, 72, 79, 85, 90, 87, 80, 74, 68, 61],
  [48, 52, 61, 68, 76, 83, 89, 86, 79, 71, 63, 55]
]
const DURATION = 0.9 // 单柱生长时长（秒）
const STAGGER = 0.03 // 相邻柱入场延迟（秒）
const HOVER_EMISSIVE = 0x3a3a3a
let renderer = null
let scene = null
let camera = null
let controls = null
let raycaster = null
const bars = []
let hovered = null
// 指针 NDC 坐标：pointermove 只记录，拾取统一放到渲染循环里做
const pointer = { x: 0, y: 0, inside: false }
let animTime = 0
let rafId = 0
let last = 0
let destroyed = false
// 缓动函数：前快后慢，物体"生长到位"的常用手感
function easeOutCubic(p) {
  return 1 - Math.pow(1 - p, 3)
}
function replay() {
  animTime = 0 // 归零时钟，生长动画从头再播
}
// 屏幕坐标归一化到 NDC（-1 ~ 1），注意 y 要取反：屏幕坐标向下，NDC 向上
function onPointerMove(e) {
  if (!renderer) return
  const rect = renderer.domElement.getBoundingClientRect()
  pointer.x = ((e.clientX - rect.left) / rect.width) * 2 - 1
  pointer.y = -((e.clientY - rect.top) / rect.height) * 2 + 1
  pointer.inside = true
}
function onPointerLeave() {
  pointer.inside = false
}
// resize 三件事：更新 aspect、重算投影矩阵、重设渲染尺寸
function onResize() {
  const el = stageRef.value
  if (!el || !renderer || !camera) return
  const w = el.clientWidth
  const h = el.clientHeight
  camera.aspect = w / h
  camera.updateProjectionMatrix()
  renderer.setSize(w, h)
}
onMounted(async () => {
  // three 与控制器都依赖浏览器环境：只能在挂载后动态 import
  const THREE = await import('three')
  const { OrbitControls } = await import('three/addons/controls/OrbitControls.js')
  // await 期间用户可能已切走（SPA 竞态）：组件已卸载则放弃初始化
  if (destroyed || !stageRef.value) return
  const el = stageRef.value
  const w = el.clientWidth
  const h = el.clientHeight
  scene = new THREE.Scene()
  scene.background = new THREE.Color(0xf7f8fa)
  // 可选雾气：远处柱体轻微淡出，增强纵深感（颜色与背景一致才自然）
  scene.fog = new THREE.Fog(0xf7f8fa, 24, 42)
  // 相机初始角度：高位斜视，让 12×3 的柱阵一次看全
  camera = new THREE.PerspectiveCamera(45, w / h, 0.1, 100)
  camera.position.set(9.5, 8, 12)
  renderer = new THREE.WebGLRenderer({ antialias: true })
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))
  renderer.setSize(w, h)
  el.appendChild(renderer.domElement)
  controls = new OrbitControls(camera, renderer.domElement)
  controls.enableDamping = true
  controls.target.set(0, 1, 0)
  controls.maxDistance = 30
  scene.add(new THREE.AmbientLight(0xffffff, 0.6))
  const dirLight = new THREE.DirectionalLight(0xffffff, 2.5)
  dirLight.position.set(6, 10, 4)
  scene.add(dirLight)
  // 地面"坐标纸"：尺寸按数据网格范围取，别让柱子悬在网格外
  scene.add(new THREE.GridHelper(13, 13, 0x999999, 0xdddddd))
  // 数据到视觉通道的映射：
  // 月份 → x（列）、城市 → z（行）；数值 → 柱高 scale.y 与颜色（HSL 蓝 0.66 → 红 0）
  // 关键坑点：translate(0, 0.5, 0) 把几何体原点移到底面中心，
  // 之后缩放 scale.y 才会"从地面生长"，否则会向上下两端同时伸长
  const geo = new THREE.BoxGeometry(0.6, 1, 0.6)
  geo.translate(0, 0.5, 0)
  for (let c = 0; c < 3; c++) {
    for (let m = 0; m < 12; m++) {
      const value = DATA[c][m]
      const v = value / 100 // 归一化
      const color = new THREE.Color().setHSL(0.66 * (1 - v), 0.75, 0.5)
      const mesh = new THREE.Mesh(
        geo,
        new THREE.MeshStandardMaterial({ color, roughness: 0.5, metalness: 0.1 })
      )
      mesh.position.set(m - 5.5, 0, (c - 1) * 1.4)
      mesh.scale.y = 0.001 // 入场前压扁到近乎为零，0 会退化成不可拾取的平面
      mesh.userData = { city: CITIES[c], month: MONTHS[m], value, fullH: 0.4 + v * 3.2 }
      scene.add(mesh)
      bars.push(mesh)
    }
  }
  raycaster = new THREE.Raycaster()
  const TOTAL_ANIM = (bars.length - 1) * STAGGER + DURATION
  // 渲染循环里统一拾取：时序与渲染一致，且天然随帧率节流
  function updateHover() {
    let hit = null
    if (pointer.inside) {
      raycaster.setFromCamera(pointer, camera)
      const hits = raycaster.intersectObjects(bars, false)
      hit = hits.length > 0 ? hits[0].object : null
    }
    // 只在 hover 目标变化时才动材质与面板，避免每帧触发组件重渲染
    if (hit === hovered) return
    if (hovered) hovered.material.emissive.setHex(0x000000)
    hovered = hit
    if (hovered) {
      hovered.material.emissive.setHex(HOVER_EMISSIVE)
      const u = hovered.userData
      infoText.value = u.city + ' · ' + u.month + ' · 数值 ' + u.value
    } else {
      infoText.value = DEFAULT_TIP
    }
    renderer.domElement.style.cursor = hovered ? 'pointer' : 'default'
  }
  last = performance.now()
  function frame(now) {
    const dt = Math.min(now - last, 33) / 1000
    last = now
    // 入场生长动画：scale.y 从 0.001 缓动到目标高度，逐柱错开；
    // 播完总时长后不再每帧写 scale，帧循环只留控制器与拾取
    if (animTime < TOTAL_ANIM) {
      animTime += dt
      for (let k = 0; k < bars.length; k++) {
        const t = (animTime - k * STAGGER) / DURATION
        const p = t < 0 ? 0 : t > 1 ? 1 : t
        bars[k].scale.y = Math.max(0.001, bars[k].userData.fullH * easeOutCubic(p))
      }
    }
    controls.update() // 阻尼生效的前提
    updateHover()
    renderer.render(scene, camera)
    rafId = requestAnimationFrame(frame)
  }
  rafId = requestAnimationFrame(frame)
  const dom = renderer.domElement
  dom.addEventListener('pointermove', onPointerMove)
  dom.addEventListener('pointerleave', onPointerLeave)
  window.addEventListener('resize', onResize)
})
onBeforeUnmount(() => {
  destroyed = true
  // 浏览器 WebGL 上下文数量有限（一般 8~16 个），泄漏会导致后续页面黑屏，必须完整释放
  cancelAnimationFrame(rafId)
  window.removeEventListener('resize', onResize)
  if (controls) controls.dispose() // 控制器内部挂了 DOM 监听，必须一并销毁
  if (scene) {
    scene.traverse((obj) => {
      if (obj.geometry) obj.geometry.dispose()
      if (obj.material) {
        const mats = Array.isArray(obj.material) ? obj.material : [obj.material]
        mats.forEach((m) => m.dispose())
      }
    })
  }
  if (renderer) {
    renderer.dispose()
    if (renderer.domElement.parentNode) {
      renderer.domElement.parentNode.removeChild(renderer.domElement)
    }
  }
  renderer = null
  scene = null
  camera = null
  controls = null
  raycaster = null
  hovered = null
  bars.length = 0
})
</script>

最佳实践与常见坑 ​

  • 以底为锚的缩放必须先 translate 几何体。BoxGeometry 原点在中心，不 translate 就改 scale.y，柱体会向两端伸缩、下半截陷进地面，生长动画变成"从中间裂开"；geometry.translate(0, 0.5, 0) 一次把原点移到底面中心，是这类动画的固定前奏。
  • 初始缩放取 0.001 不取 0。缩放为 0 的柱体退化成平面，射线拾取直接落空，动画起点附近 hover 会莫名其妙失灵；近乎零的一个小值既不可见又保持可拾取。
  • 柱高要有下限。数值为 0 的柱子高度也是 0 时，它在视觉与拾取上同时"消失"，用户会以为数据缺失；映射公式保留一个下限（本例 0.4），让最小值也有存在感，数值交给面板与颜色表达。
  • 颜色用 HSL 插值而不是写死色板。色相单通道承载数值、饱和度亮度固定，数据范围变化时渐变自动适应；RGB 三通道插值出来的渐变中间色浑浊，蓝→绿→黄→红的多段色板又引入额外跳变。
  • hover 面板更新要做变化检测。面板文案是 Vue 响应式状态，每帧赋值会触发组件每帧重渲染，成本远超拾取本身；像组件一样"hovered 引用变了才更新"，把重渲染压到最少。
  • 柱体上量后再考虑 InstancedMesh。几百根以内普通 Mesh 足够，每根一个 draw call 毫无压力；数千根时 draw call 数量成为瓶颈，InstancedMesh 合并成一次绘制，但单柱高亮要改用 instanceColor 按索引改色，别提前优化。
  • 网格尺寸按数据范围算。GridHelper 是装饰也是参照系，柱阵 11×2.8 的占地面积配 13 格刚好；网格远小于柱阵会让边缘柱子"悬空"，远大于柱阵又失去参照意义。

小结 ​

要点回顾：3D 柱状图 = 双类目轴铺地面网格 + 数值映射柱高与颜色，思想与 2D 柱状图同构，成本在视角与遮挡；场景搭建是清单式套路，相机机位、双灯、坐标纸网格、可选雾气；柱体共享几何体、独立材质，geometry.translate(0, 0.5, 0) 是"从地面生长"的前提；HSL 蓝到红的色相插值承担数值编码；hover 数值用 DOM 面板而非 3D 文字，是复杂度与收益的理性取舍；生长动画以 0.001 起步、easeOutCubic 收尾、播完即停。至此 Three.js 章节完结，下一篇 技术全景与分类框架进入对比分析模块，把 Canvas、SVG、Fabric、ECharts、Three.js 放回同一张地图上审视选型。
