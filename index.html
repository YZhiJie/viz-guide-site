快速开始 ​

环境要求：Node.js 18+、pnpm 8+。

bash
pnpm install
pnpm dev

执行单一命令即可启动整个站点——所有章节的示例都内嵌在页面中，打开终端提示的地址（默认 http://localhost:5173，端口被占用时自动顺延）即可交互体验，无需任何额外配置。
